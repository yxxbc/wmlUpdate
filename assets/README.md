# Brand assets

| File | Use |
| --- | --- |
| `logo.svg` | Editable vector source (uses Avenir Next Condensed, with sans fallback) |
| `logo.png` | Canonical 512 px mark for README, docs and UI |
| `logo-1024.png` | 1024 px raster fallback |
| `social-preview.svg` | Editable 1280×640 social card |
| `social-preview.png` | GitHub repository social preview |

The GitHub social preview must be uploaded manually in **Settings → General →
Social preview**. Use `social-preview.png`.
